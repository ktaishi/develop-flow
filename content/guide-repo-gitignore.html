.gitignore

秘密情報と生成物の除外。

このページで押さえること

  • .env 実体・シークレットは除外すると決める
  • rules・テンプレ類はコミット対象に含める
  • コミット前に git check-ignore で確認する

.gitignore

方針

コミット対象と除外対象の例

コミット: .cursor/rules/、AGENTS.md、.env.example / 除外: .env、docker-compose.override.yml、node_modules/

  • コミットすべき: .cursor/rules/ / AGENTS.md / CLAUDE.md / 共有 .claude/skills/ / .agents/skills/ / .codex/config.toml* / .env.example / Docker 関連 / Makefile
  • コミットしない: .env 実体 / シークレット / キャッシュ / ビルド成果物 / 個人 IDE 設定
  • テンプレは github/gitignore を組み合わせる
